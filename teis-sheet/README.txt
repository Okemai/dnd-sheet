Лист Тейса Бракмана — D&D 5e (2014). PWA, работает без интернета. Сделан на базе листа Ааза.

Как разместить:
1) GitHub Pages: новый репозиторий (например, teis-sheet) — залей содержимое папки в корень,
   Settings → Pages → Deploy from branch → main / root. Адрес: https://<ник>.github.io/teis-sheet/
   Можно и папкой внутри dnd-sheet (dnd-sheet/teis/) — листы не мешают друг другу:
   у них разные ключи хранилища и разные кэши.
2) Или Netlify Drop: https://app.netlify.com/drop — перетащи папку целиком.

Установка на планшет — как у Ааза: Chrome ⋮ → «Установить приложение», iPad Safari → «На экран „Домой“».

Вкладки: Бой · Лист · Чары · Мастерская · Душа.
- «✎ Правка» открывает цифры, владения (тап по фиолетовой линзе), оружие, эффекты пистолета, заклинания, инфузии.
- Тап по любому бонусу — бросок к20 (помеха/преимущество в окне броска).
- Пистолет: «Чародейское копьё» бросает столько атак, сколько эффектов осталось в этом действии (на 5 ур. — 2).
  «Шоковый разряд» и «Громовой залп» тратят по одному эффекту. Кружки сверху — эффекты текущего действия.
  Если эффектов не осталось, выстрел считается бонусным (после заклинания действием).
- Ячейки — шестерёнки по кругам. Возвращаются только после долгого отдыха.
  Если заклинание усиливается, лист спросит, какой ячейкой накладывать, и пересчитает урон.
- «Щит» поднимает КД на +5 до «Нового хода». «Раскалённый металл» на концентрации даёт кнопку «бонусом» для повторного урона.
- Ворона (гомункул) появляется на «Бое», пока её инфузия активна: хиты, силовой удар, оживление ячейкой.
- Мастерская: инфузии (тап по шестерёнке — зажечь/погасить; лимит 2 предмета на 5 ур.), амулет здоровья
  (снял — ТЕЛ 8 и максимум хитов 23, надел — ТЕЛ 19 и 48), снаряжение, тайна, добыча.
- Повышение уровня: в правке поменяй «Уровень» и «Макс. хиты без амулета» — БМ, ячейки, число эффектов пистолета,
  лимиты инфузий и настройки, хиты вороны пересчитаются сами.
- Тап по портрету — арт целиком. Темы «Кеттердам», «Пергамент», «Бочка» — в меню ☰.

Герой хранится в памяти устройства. Резервная копия — ☰ → «Экспорт героя» (файл .teis.json),
перенос на другое устройство — «Импорт героя».
